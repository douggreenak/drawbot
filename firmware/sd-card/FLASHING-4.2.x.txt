DRAWBOT FIRMWARE - Creality 4.2.x board (4.2.2 / 4.2.7)
=========================================================
This folder has the firmware for your board:
  drawbot-....bin   the firmware (Marlin, patched for pen plotting)

1. Use a microSD card of 32 GB or smaller, formatted FAT32 with a 4096-byte cluster size.
   Copy the .bin file to the root of the card. Only one .bin should be on the card.
2. Printer OFF. Insert the card. Switch the printer ON.
3. The screen stays blank for 20-30 s while it flashes, then the screen appears.
   If nothing happens, the .bin name must differ from the firmware already installed -
   that is why the name contains a timestamp.
4. Check: connect in the Drawbot web app; the machine name reads "Drawbot".
5. Delete the .bin from the card afterwards.

Make sure this folder matches the version printed on your board (4.2.2 vs 4.2.7). Works on both the
STM32F103RET6 and RCT6 chips.

NOT TESTED ON HARDWARE by the build system. If the screen stays blank, power off, remove the card and
re-flash the original Creality firmware from creality.com, then try again.
